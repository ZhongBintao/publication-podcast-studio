设计说明 · Design Rationale

色彩系统

暖米白背景替代冰冷深灰，营造杂志纸张质感
经济学人红用于 kicker、编号、装饰线
深墨主文字 + 灰阶层次

字体层级

英文标题/问题统一使用 Georgia 衬线体，传承经济学人编辑基因；中文使用 Noto Sans SC 无衬线体保证屏显清晰；UI 标签使用 Helvetica 大写小字间距，形成三级字体节奏。

图片系统

封面与文章配图统一采用无边框纯阴影极简悬浮：无白边、无描边，仅靠两层柔和投影（近景细微 + 远景扩散）让图片自然浮于米白纸面之上。图片 contain 放置保持原始比例，底部渐变过渡消除生硬边界。

字幕系统

无背景 + 文字描边投影：摒弃渐变遮罩与黑色底栏，字幕直接浮于画面。英文白色粗体加 1.5px 深色描边 + 柔和投影；中文白色加 1px 描边 + 投影。双语居中垂直排列，零画面遮挡，无闪烁，在任何背景上均保证可读性。

布局结构

横版采用左右分栏（文字 55% / 图片 45%），竖版采用上下分栏（图片 42-46% / 文字 54-58%）。开篇页突出标题与封面，内容页以红色编号引导问题，图片底部带渐变过渡消除生硬边界。

细节处理

红色短装饰线建立视觉锚点；细分隔线区分信息区块；图片带细微投影浮于纸面；图片说明使用斜体小字；元数据行用红点分隔，整体保持克制、呼吸感与编辑级品质。

与旧版差异

旧版：深灰底 + 纯白文字 + 纯黑字幕栏 + 松散排版 + 内容页重复封面。新版：暖米白纸感 + 灰阶文字层次 + 无背景描边字幕 + 无边框极简悬浮图片 + 紧凑编辑级排版 + 内容页使用文章配图轮播。
